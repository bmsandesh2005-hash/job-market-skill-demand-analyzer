# Dataset notes

Place your selected job-postings CSV here and name it `job_postings.csv`.

Before using a dataset:
- Confirm that its license and terms permit your intended use.
- Record the source URL, access date, geographic coverage, and date range in the project report.
- Keep personal or confidential data out of the repository.
- Do not commit a dataset if redistribution is not permitted.

The starter analysis expects a `description` column. Optional columns include `title`, `location`, `company`, and `salary`.
